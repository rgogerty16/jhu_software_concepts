The headline accuracy of 0.8111 is measured on a test fold where 39.0% of
rows carry a comment describing the outcome. On those rows the model scores
0.8885. On rows with no outcome language available at all - the situation
every user of the web form is in, since nobody can describe a decision they
have not received - it scores 0.7617, which is -0.0495 against the headline.

That second number, 0.7617, is the honest estimate of deployed performance,
and it is the one the write-up leads with when discussing what this system
would actually do for a real applicant. It is still well above the 0.5394
majority-class baseline, so the model has learned something real about
programs, degrees, and scores. But the gap is a reminder that a held-out
test set only protects against memorizing rows, not against a feature that
encodes the answer.

This script changes nothing. It only measures the saved model.
